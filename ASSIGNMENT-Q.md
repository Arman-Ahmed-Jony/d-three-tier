# Assignment: The Friday Night Fix
CloudNest DevOps Challenge  |  Total Marks: 100

## The Scenario
Rafi is a junior developer at a small startup called CloudNest. On Friday evening, his team lead, Nadia, sends him a message:

“Rafi, our main branch is a mess, our CI depends on a paid cloud service we’re cancelling, and we can’t see what’s happening on our server. The client demo is on Monday. I need you to sort this out over the weekend.”

Rafi opens his laptop and finds the problems one after another.

## Your Tasks
### Task 1: Starting Fresh
Nadia wants new work kept separate from the main branch. Rafi has to set up the repository so his new feature work and the main code stay apart.

### Task 2: Interrupted Work
While Rafi is halfway through a change, Nadia calls about an urgent bug on another branch. His current work isn’t ready to commit, but he can’t lose it either. After fixing the bug, he needs to get his unfinished work back exactly as he left it.

### Task 3: Cleaning the History
Rafi’s feature branch is now behind main. Nadia wants the feature brought up to date once with a clean, linear history, and once with the full branch history preserved, so she can compare the two approaches and choose one for the team.

### Task 4: The Embarrassing Message
Rafi notices he wrote “asdf fix” as a commit message. Nadia won’t accept that in the project history, so the message has to be corrected before anyone sees it.

### Task 5: Our Own CI
CloudNest is cancelling its paid CI service. Rafi has to make the project build and test automatically on every push, using a machine the company controls instead of a hosted runner.

### Task 6: The Blind Server
The server sometimes slows down and nobody knows why. Nadia wants system metrics from the machine collected and stored, gathered by a modern telemetry agent, and viewable in a visualization tool.

### Task 7: The Dashboard
For Monday’s demo, Nadia wants a dashboard built by hand, not imported, that shows the server’s health at a glance: CPU, memory, disk, and network.

## Your Mission

Rafi has no guide and no help, only the problem. You are Rafi. Solve it, and submit proof: repository link, screenshots, and a short write-up of what you did and why.
